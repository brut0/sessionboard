ADR-0001 · Packaging
Single Multi-Stage Container

Node 22 builds the React 19 SPA into backend/app/static; Python 3.12 + FastAPI serves both /api/* and static assets on one port.

ADR-0002 · Cloud & Cost
Render + 2× Neon + Grafana

Separate Neon projects for dev and prod (100 CU-h each, no 30-day expiry). Hourly synthetic probe keeps Render inside 750 free hours/mo.

ADR-0003 · Concurrency
Sync psycopg 3 + Advisory Lock

pg_advisory_xact_lock(hashtext(date)) serializes same-day bookings without cross-date contention or Windows async loop issues.

Criteria 10–12 · SRE Loop
